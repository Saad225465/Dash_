# 🔴 Phase 8 — Callbacks ⭐

This is probably the **most important Dash topic**.

Callbacks make your dashboard interactive.

For example:

```text
User selects country
        ↓
Dropdown
        ↓
Callback
        ↓
Filter data
        ↓
Update graph
```

Basic callback:

```python
from dash import Input, Output, callback

@callback(
    Output("my-output", "children"),
    Input("my-button", "n_clicks")
)
def update_text(n_clicks):
    return f"You clicked {n_clicks} times"
```

Understand these very carefully:

### Input

```python
Input()
```

### Output

```python
Output()
```

### Callback

```python
@callback()
```

### Component ID

```python
id="my-button"
```

# 🔴 Phase 9 — Interactive Graphs

Now combine callbacks + Plotly.

Example:

```text
Dropdown
   ↓
Callback
   ↓
Filter Pandas DataFrame
   ↓
Create Plotly figure
   ↓
dcc.Graph
```

Example:

```python
@callback(
    Output("graph", "figure"),
    Input("country", "value")
)
def update_graph(country):

    filtered = df[df["country"] == country]

    fig = px.line(
        filtered,
        x="year",
        y="sales"
    )

    return fig
```

This is where Dash starts becoming really powerful.

# 🔴 Phase 12 — State

Learn the difference between:

```python
Input
```

and:

```python

```

`Input` triggers the callback.

`State` provides a value without triggering the callback by itself.

This becomes useful for:

* Search boxes
* Forms
* Buttons
* Filters
